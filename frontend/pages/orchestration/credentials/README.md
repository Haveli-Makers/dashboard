### Description

This interface serves as the Credential Management Hub for Bot orchestration. It allows to securely store and organize API keys and other account details required to deploy bot instances across various exchanges:

- **Account Organization**: Create and manage distinct account profiles to keep trading environments separated.
- **Credential Integration**: Add and update API keys and secrets for specific connectors.
- **Sub-Account Management**: Enables management of subaccounts as well.
- **Secure Management**: Easily delete outdated credentials or remove entire account profiles that are no longer in use.
